Занятие 04. Потенциометр. Аналоговые сигналы. RGB-светодиод

Потенциометр — переменный резистор с тремя выводами. При вращении ручки изменяется положение внутреннего контакта — ползунка. В наших схемах два крайних вывода получают 5 В и GND, а средний выдаёт напряжение между ними.

Это делитель напряжения: например, при положении посередине на среднем выводе получится примерно 2,5 В. Arduino может измерить это напряжение и превратить поворот ручки в команду.

⭐ Главное запомнить

В роли делителя напряжения потенциометр имеет три контакта, а показание берётся со среднего. Поменяешь крайние 5 В и GND местами — поменяется направление регулировки.

⚠️ Типичные ошибки

Не подключай средний контакт прямо к GND или 5 В при одновременном использовании его как сигнала. Не путай контакты, ориентируйся по выводам именно своего потенциометра. Собирай схему при отключённом USB.

Схема из приложенных материалов — нажмите для увеличения.

Потенциометр: поворот ручки изменяет напряжение на среднем выводе.

Цифровой вход отвечает в основном «0 или 1». Аналоговый вход измеряет величину напряжения. На классической Arduino Uno R3 входы обозначены A0–A5; команда analogRead(A0) возвращает целое число от 0 до 1023 при стандартном опорном диапазоне от 0 до 5 В.

Почему именно 1023? Аналого-цифровой преобразователь (АЦП) Uno R3 имеет 10 бит, значит, различает 210 = 1024 уровня (с номерами от 0 до 1023).

0 ВОколо 0
2,5 ВОколо 512
5 ВОколо 1023
⭐ Главное запомнить

analogRead() считывает вход. Его результат — число, а не напряжение в вольтах. Если нужно получить приблизительные вольты: U ≈ reading * 5.0 / 1023.0.

⚠️ Типичные ошибки

Плавающий, никуда не подключённый вход может показывать случайные числа. Не превышай допустимый диапазон входа Uno R3 — 0–5 В относительно GND.

На Arduino Uno аналоговые входы обозначаются A0–A5.

В занятии 03 мы изучили ШИМ: светодиод очень быстро включается и выключается, а зрительно кажется, что меняется яркость. analogWrite() принимает число от 0 до 255 на поддерживаемом PWM-выводе.

Но analogRead() даёт 0–1023. Поэтому для обычной Uno удобно преобразовать число: brightness = analogRead(A0) / 4;. Другой вариант — функция map(). В Arduino Uno PWM-выводы: D3, D5, D6, D9, D10, D11.

⭐ Главное запомнить

analogRead(A0) — считывание 0–1023; analogWrite(9, value) — управление яркостью 0–255.

⚠️ Типичные ошибки

Не путай A0 (вход для измерений) и D9 (выход PWM для яркости). На классической Uno D2 и D4 не являются PWM-выводами.

При ШИМ меняется доля времени, когда сигнал включён: 25%, 50%, 75%.

RGB — это Red (красный), Green (зелёный), Blue (синий). Внутри одного корпуса находятся три светодиода. Если включать каналы вместе с разной яркостью, можно получать множество оттенков: красный + зелёный = жёлтый, красный + синий = пурпурный, зелёный + синий = голубой.

RGB-светодиоды бывают с общим катодом (общий контакт соединяют с GND) и с общим анодом (общий контакт соединяют с +5 В). Приведённая вами схема рассчитана на общий катод. В зависимости от разновидности светодиода порядок ножек проверяют по документации детали.

В приложенной схеме каналы выведены на D2 (красный), D3 (синий), D4 (зелёный), общий контакт — на GND через резистор. Этой схемы достаточно, чтобы включать сочетания цветов цифровыми командами HIGH и LOW. Для независимого плавного управления яркостью каждого цвета понадобится другая схема с тремя PWM-пинами и отдельным резистором на канал.

⭐ Главное запомнить

В RGB есть 3 цветовых канала и общий вывод. Для схемы с общим катодом HIGH включает канал, а для общего анода логика обратная.

⚠️ Типичные ошибки

Нельзя считать, что у любого RGB одинаковое расположение контактов. Один общий резистор, как в примере-фотографии, может давать неравномерную яркость при одновременном включении каналов — для точного управления ставь по резистору на R, G, B.

Предоставленная RGB-схема, увеличение по щелчку.

Если каждому цвету назначить отдельный PWM-пин, например R→D9, G→D10, B→D11, мы можем установить величину яркости каждого канала независимо. Например: analogWrite(9, 255) — максимальный красный, analogWrite(10, 128) — половинная яркость зелёного.

Удобный эксперимент — три потенциометра, каждый управляет своим цветом: A0→R, A1→G, A2→B. Программа считывает три числа 0–1023, переводит их в диапазон 0–255 и отправляет значения в три PWM-выхода. Получается физический пульт для настройки оттенков.

Каждый канал RGB можно представить числом от 0 до 255. Три PWM-выхода и три потенциометра позволяют создать полностью управляемый источник цвета.

⚠️ Типичные ошибки

Все GND должны быть общими. Не пропускай индивидуальные резисторы 220–330 Ом для каналов RGB. Если используешь общий анод, переворачивай уровень яркости программно: 255 - value.

При сложении света красный, зелёный и синий образуют новые цвета и белый свет.

ПРАКТИЧЕСКАЯ РАБОТА 1

🎚️ Потенциометр регулирует яркость светодиода

Собери цепь, в которой положение ручки превращается в яркость светодиода. Эта работа основана на приложенном материале «Светильник с управляемой яркостью»; скетч использует A0 и D9. Приложенный swanky_esboo1.ino также читает A0, но делит значение на 10, поэтому максимальная яркость в нём ниже: около 102 вместо 255. Ниже приведён вариант для всего диапазона.

Алгоритм сборки
  1. Отключи Arduino от USB. Установи потенциометр и светодиод на макетную плату.
  2. Крайние контакты потенциометра подключи к 5V и GND; средний — к A0.
  3. Анод светодиода подключи через резистор 220–330 Ом к D9, катод — к GND.
  4. Объедини землю потенциометра и светодиода с GND Arduino; проверь дорожки макетки.
  5. Подключи USB. В Arduino IDE выбери Uno и порт, вставь программу и загрузи её.
  6. Медленно вращай ручку. Сравни яркость при минимальном, среднем и максимальном положении.

Пошаговый разбор программы

1. Объявляем POT = A0 и LED = 9.
2. pinMode(LED, OUTPUT) подготавливает светодиодный выход.
3. analogRead(POT) получает значение 0–1023.
4. Делим его на 4 и получаем яркость 0–255.
5. analogWrite(LED, brightness) меняет яркость.
pot_led.ino · C++
const int POT = A0;          // средний контакт потенциометра
const int LED = 9;           // PWM-выход

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int reading = analogRead(POT); // 0...1023
  int brightness = reading / 4;  // 0...255
  analogWrite(LED, brightness);
  delay(10);
}
Проверь результат

При вращении ручки яркость меняется плавно. Если это не так, проверь средний контакт A0, GND и PWM-пин D9.

ПРАКТИЧЕСКАЯ РАБОТА 2

🌈 RGB-светодиод: переключаем цвета

Используй приложенную схему с четырьмя выводами RED, GND, BLUE, GREEN. На схеме: красный → D2, синий → D3, зелёный → D4, общий катод → GND. Программа включает каналы по очереди, а затем одновременно.

Важная особенность схемы

На исходной фотографии показан один общий резистор. Для стабильных смешанных цветов лучше добавить три резистора 220–330 Ом — по одному в каждую линию R, G, B. Ни один цветовой канал нельзя подключать к цифровому пину напрямую без ограничения тока.

Алгоритм сборки
  1. Проверь по маркировке своего RGB-светодиода, какой вывод общий. Эта схема — для общего катода.
  2. Отключи питание, установи RGB LED на макетную плату, подключи общий вывод к GND.
  3. Подключи RED к D2, BLUE к D3, GREEN к D4 через ограничение тока согласно схеме.
  4. После проверки цепи подключи USB и загрузи скетч.
  5. Наблюдай переключение красного, зелёного, синего и их общего включения.

Пошаговый разбор программы

1. Три константы задают номера выводов D2, D3 и D4.
2. В setup() все три настроены на OUTPUT.
3. digitalWrite() управляет отдельными цветовыми каналами.
4. delay(1000) удерживает цвет одну секунду.
5. Все три HIGH дают сумму трёх основных цветов, близкую к белой; оттенок зависит от LED и резисторов.
rgb_colors.ino · C++
const int RED = 2;   // согласно приложенной схеме
const int BLUE = 3;
const int GREEN = 4;

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(BLUE, OUTPUT);
  pinMode(GREEN, OUTPUT);
}

void loop() {
  // Красный
  digitalWrite(RED, HIGH);
  digitalWrite(BLUE, LOW);
  digitalWrite(GREEN, LOW);
  delay(1000);

  // Зелёный
  digitalWrite(RED, LOW);
  digitalWrite(BLUE, LOW);
  digitalWrite(GREEN, HIGH);
  delay(1000);

  // Синий
  digitalWrite(RED, LOW);
  digitalWrite(BLUE, HIGH);
  digitalWrite(GREEN, LOW);
  delay(1000);

  // Белый (все три канала)
  digitalWrite(RED, HIGH);
  digitalWrite(BLUE, HIGH);
  digitalWrite(GREEN, HIGH);
  delay(1000);
}
Проверь результат

Убедись, что цвета загораются в нужном порядке. Для плавной регулировки всех трёх каналов эта схема не подходит: D2 и D4 не поддерживают PWM на Uno. Следующая работа использует D9, D10 и D11.

🎛️ Три потенциометра — собственный RGB-пульт

Расширенный проект: три потенциометра управляют каждым каналом RGB независимо. Это новая схема для третьей работы, она отличается от изображения во второй работе. Используется RGB с общим катодом.

Алгоритм сборки
  1. Отключи питание и установи три потенциометра и RGB-светодиод на макетную плату.
  2. Все крайние выводы потенциометров подключи параллельно к 5V и GND, но не замыкай линии 5V и GND напрямую.
  3. Средние контакты потенциометров подключи к A0, A1, A2 соответственно.
  4. Общий катод RGB соедини с GND. Выводы R, G, B подключи через три отдельных резистора к PWM D9, D10 и D11.
  5. Проверь схему, подключи USB, выбери Arduino Uno и порт, загрузи программу.
  6. Поворачивай ручки по отдельности и одновременно. Подбери фиолетовый, бирюзовый, белый, жёлтый оттенки.

Разбираем код по этапам

1. В массиве pots[] лежат три аналоговых входа A0–A2.
2. В массиве colors[] — три PWM-выхода D9–D11.
3. Цикл for в setup() настраивает три выхода.
4. Второй for считывает каждый потенциометр, делит результат на 4 и посылает его в свой RGB-канал.
5. Цикл выполняется постоянно, поэтому цвет меняется сразу после поворота ручки.
rgb_3_pots.ino · C++
// Три потенциометра, RGB с общим катодом
const int pots[3] = {A0, A1, A2};
const int colors[3] = {9, 10, 11}; // R, G, B — PWM

void setup() {
  for (int i = 0; i < 3; i++) {
    pinMode(colors[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < 3; i++) {
    int sensorValue = analogRead(pots[i]);
    int brightness = sensorValue / 4;
    analogWrite(colors[i], brightness);
  }
  delay(10);
}
Проверь результат

Каждая ручка должна изменять только свой канал. Если вместо увеличения яркость уменьшается, поменяй местами крайние контакты соответствующего потенциометра при отключённом питании.
