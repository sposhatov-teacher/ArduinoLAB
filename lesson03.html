В электронном устройстве электрический ток движется по замкнутой цепи. Представь воду в трубах: напряжение похоже на давление, сила тока — на количество воды, проходящей за секунду, а сопротивление — на узкое место, которое мешает потоку.

У Arduino Uno цифровой выход в состоянии HIGH обычно даёт около 5 В относительно GND. Но светодиоду нельзя подавать неограниченный ток — поэтому мы включаем последовательно резистор.

Напряжение UИзмеряется в вольтах (В). Оно создаёт условия для движения зарядов.
Сила тока IИзмеряется в амперах (А). Показывает, сколько заряда проходит за секунду.
Сопротивление RИзмеряется в омах (Ω). Ограничивает электрический ток.
⭐ Главное запомнить
  • Цепь для светодиода должна быть замкнутой: вывод Arduino → резистор → LED → GND.
  • Плюс и минус у светодиода важны: у него есть анод и катод.
  • Собирать или изменять провода нужно при отключённом питании.
⚠️ Где можно ошибиться
  • Не подключай Arduino к бытовой сети 220 В.
  • Не соединяй вывод 5V с GND напрямую — это короткое замыкание.
Резистор помогает безопасно ограничить силу тока в цепи.
Пример: почему при увеличении сопротивления светодиод обычно светится слабее? Потому что через него проходит меньший ток.

Закон Ома связывает три величины: I = U / R. Это значит: чем больше сопротивление при одном и том же напряжении, тем меньше сила тока.

У светодиода есть собственное падение напряжения. Поэтому для выбора резистора точнее использовать формулу R = (Uпитания − Uсветодиода) / I.

Пример расчёта
  1. Arduino: 5 В; красный LED: примерно 2 В; желаемый ток: 0,01 А (10 мА).
  2. На резисторе останется 5 − 2 = 3 В.
  3. Требуемое сопротивление: R = 3 / 0,01 = 300 Ом.
  4. Подойдёт близкий стандартный номинал 330 Ом; в обычных учебных схемах также часто применяют 220 Ом, если характеристики LED позволяют.
⭐ Главное запомнить
  • В законе Ома I = U / R, где I — амперы, U — вольты, R — омы.
  • Для LED учитывай и его падение напряжения.
  • На один отдельный светодиод — свой последовательный резистор.
⚠️ Где можно ошибиться
  • Не путай 10 мА и 10 А: 10 мА = 0,01 А.
  • Не используй сопротивление 0 Ом в цепи LED.
  • 20 мА для пина Arduino Uno — уже ориентир по паспортным характеристикам, а не цель, к которой обязательно стремиться.
Для любознательных: два резистора, подключённых последовательно, дают суммарное сопротивление R₁ + R₂. Параллельное соединение уменьшает общее сопротивление.
В практических работах выбираем 220–330 Ом.

На маленьком резисторе трудно напечатать число. Поэтому производители используют цветные полоски. Они показывают цифры, множитель и допустимую погрешность.

Например, для резистора 220 Ом в распространённой четырёхполосной маркировке: красный – красный – коричневый – золотой. Две первые полосы дают число 22, третья умножает на 10, четвёртая говорит о допуске ±5%.

220 ΩКрасный · красный · коричневый · золотой
1 кΩКоричневый · чёрный · красный · золотой
10 кΩКоричневый · чёрный · оранжевый · золотой
⭐ Главное запомнить
  • Цвет полосок показывает сопротивление в омах, а не максимальное напряжение.
  • Читать нужно с правильного края; полоса допуска обычно немного отделена.
  • Номинал можно дополнительно проверить мультиметром.
⚠️ Где можно ошибиться
  • Не путай третий множитель с допуском.
  • У резисторов с пятью полосами схема чтения отличается от четырёхполосной.

С Arduino Uno можно не только включать светодиоды, но и управлять ими по заданному порядку. Для светофора нам понадобятся три разных цифровых вывода: D2 — красный LED, D3 — жёлтый, D4 — зелёный.

Сначала в setup() делаем пины выходами с помощью pinMode(..., OUTPUT). Затем в loop() задаём каждому состоянию HIGH (включить) или LOW (выключить) и используем delay() для выдержки времени.

Алгоритм обычного светофора
  1. Красный горит, зелёный и жёлтый выключены.
  2. Жёлтый горит, остальные выключены.
  3. Зелёный горит, остальные выключены.
  4. Повторяем цикл.
⭐ Главное запомнить
  • Каждый светодиод подключён к своему цифровому пину и через свой резистор.
  • Пин в программе должен совпадать с пином на схеме.
  • Команды digitalWrite() и delay() задают последовательность сигналов.
⚠️ Где можно ошибиться
  • На рисунке используются D2, D3 и D4; нельзя произвольно заменить номера в коде.
  • Нельзя включать все LED одновременно, если задача требует последовательного переключения.
Ваша схема: контроллер Uno, макетная плата, три LED, три резистора и провода D2, D3, D4.

Обычные цифровые выходы дают только два состояния: LOW и HIGH. А чтобы светодиод светил плавно ярче или слабее, применяется ШИМ (PWM). Arduino быстро включает и выключает вывод; меняется доля времени, когда он включён, и глаз видит разную яркость.

В Arduino Uno Rev3 аппаратная ШИМ предусмотрена на пинах 3, 5, 6, 9, 10, 11. Команда analogWrite(pin, value) принимает яркость от 0 до 255.

analogWrite(9, 0)Светодиод выключен.
analogWrite(9, 127)Примерно половинная яркость.
analogWrite(9, 255)Максимальная яркость.
⭐ Главное запомнить
  • PWM — это быстрые импульсы, а не настоящий плавный аналоговый выход у Uno R3.
  • Число 0–255 задаёт яркость; для опыта Fade используется PWM-пин.
⚠️ Где можно ошибиться
  • Пин D4 не подходит для аппаратного PWM на Uno R3.
  • Не путай analogRead() (чтение входа) и analogWrite() (ШИМ-управление выходом).
Импульсы: чем дольше высокий уровень в каждом периоде, тем ярче LED.

В некоторых материалах встречается прямое управление портами. Это способ одновременно изменять несколько пинов с помощью специальных регистров микроконтроллера ATmega328P.

На Uno R3 цифровые пины объединены в группы: PORTD — D0–D7, PORTB — D8–D13, PORTC связан с аналоговыми A0–A5. Регистры DDR задают направления работы, PORT — выходные состояния, PIN — считываемые входы.

Прямое управление портами — уже более сложная техника. Для первых проектов мы используем понятные команды pinMode() и digitalWrite().

⭐ Главное запомнить
  • Порт — это группа выводов контроллера.
  • Для начинающих безопаснее и понятнее работать с отдельными пинами стандартными командами.
⚠️ Где можно ошибиться
  • Прямые команды с регистрами зависят от модели микроконтроллера.
  • Пины D0 и D1 используются для последовательного обмена и могут мешать загрузке кода.

Алгоритм сборки и запуска
  1. Отключи USB на время сборки и размести три светодиода на макетной плате по схеме.
  2. Подключи отдельный резистор 220–330 Ом последовательно к каждому LED.
  3. Соедини красный светодиод с D2, жёлтый с D3, зелёный с D4.
  4. Соедини общую линию минуса на макетной плате с GND Arduino.
  5. Сверь длинные и короткие ножки светодиодов по схеме и проверь отсутствие коротких замыканий.
  6. Подключи USB, открой Arduino IDE, выбери Arduino Uno и нужный порт.
  7. Скопируй полный код, проверь его кнопкой «Проверить», затем нажми «Загрузить».
  8. Наблюдай последовательность: красный → жёлтый → зелёный → снова красный.

Разбор программы по этапам

Шаг 1. Выбор выводов
const int redLed = 2;
const int yellowLed = 3;
const int greenLed = 4;

Каждому LED назначаем свой цифровой вывод точно по схеме.

Шаг 2. Настройка выходов
void setup() {
  pinMode(redLed, OUTPUT);
  pinMode(yellowLed, OUTPUT);
  pinMode(greenLed, OUTPUT);
}

Arduino должна знать, что эти выводы управляют устройствами.

Шаг 3. Включаем красный
digitalWrite(redLed, HIGH);
digitalWrite(yellowLed, LOW);
digitalWrite(greenLed, LOW);
delay(3000);

Красный светится 3 секунды, остальные выключены.

Шаг 4. Переключаем на жёлтый
digitalWrite(redLed, LOW);
digitalWrite(yellowLed, HIGH);
digitalWrite(greenLed, LOW);
delay(1000);

Теперь жёлтый светится 1 секунду.

Шаг 5. Включаем зелёный
digitalWrite(redLed, LOW);
digitalWrite(yellowLed, LOW);
digitalWrite(greenLed, HIGH);
delay(3000);

Зелёный светится 3 секунды; затем функция loop() начинается снова.

Полная программа на C++

traffic_light.ino · C++
// Светофор: красный D2, жёлтый D3, зелёный D4 const int redLed = 2; const int yellowLed = 3; const int greenLed = 4; void setup() { pinMode(redLed, OUTPUT); pinMode(yellowLed, OUTPUT); pinMode(greenLed, OUTPUT); } void loop() { // Красный digitalWrite(redLed, HIGH); digitalWrite(yellowLed, LOW); digitalWrite(greenLed, LOW); delay(3000); // Жёлтый digitalWrite(redLed, LOW); digitalWrite(yellowLed, HIGH); digitalWrite(greenLed, LOW); delay(1000); // Зелёный digitalWrite(redLed, LOW); digitalWrite(yellowLed, LOW); digitalWrite(greenLed, HIGH); delay(3000); } 
// Светофор: красный D2, жёлтый D3, зелёный D4
const int redLed = 2;
const int yellowLed = 3;
const int greenLed = 4;

void setup() {
  pinMode(redLed, OUTPUT);
  pinMode(yellowLed, OUTPUT);
  pinMode(greenLed, OUTPUT);
}

void loop() {
  // Красный
  digitalWrite(redLed, HIGH);
  digitalWrite(yellowLed, LOW);
  digitalWrite(greenLed, LOW);
  delay(3000);

  // Жёлтый
  digitalWrite(redLed, LOW);
  digitalWrite(yellowLed, HIGH);
  digitalWrite(greenLed, LOW);
  delay(1000);

  // Зелёный
  digitalWrite(redLed, LOW);
  digitalWrite(yellowLed, LOW);
  digitalWrite(greenLed, HIGH);
  delay(3000);
}
Проверка результата: светофор последовательно зажигает красный, жёлтый, зелёный. Если LED не светит, проверь направление его ножек, резистор, общий GND и точное соответствие D2/D3/D4.

Схема из учебного материала: анод LED через резистор к D3 (PWM), катод — к GND.

Алгоритм сборки и запуска
  1. Отключи питание платы перед подключением компонентов.
  2. Установи один светодиод; длинную ножку подключи через резистор 220–330 Ω к выводу D3 (~).
  3. Короткую ножку LED соедини с GND Arduino.
  4. Подключи плату к компьютеру по USB и открой Arduino IDE.
  5. Вставь код Fade, проверь синтаксис и загрузи программу.
  6. Посмотри: LED должен постепенно ярчать и затем тускнеть.

Разбор программы по этапам

Шаг 1. Переменные
const int ledPin = 3;
int brightness = 0;
int stepBrightness = 5;

D3 поддерживает ШИМ. brightness — текущая яркость, stepBrightness — величина изменения.

Шаг 2. Режим пина
pinMode(ledPin, OUTPUT);

Настраиваем выбранный контакт как выход.

Шаг 3. Устанавливаем яркость
analogWrite(ledPin, brightness);

Значение от 0 до 255 задаёт долю времени включения PWM-сигнала.

Шаг 4. Изменяем и разворачиваем
brightness += stepBrightness;
if (brightness <= 0 || brightness >= 255) {
  stepBrightness = -stepBrightness;
}

На границах 0 и 255 направление изменения яркости меняется.

Шаг 5. Делаем короткую паузу
delay(30);

Небольшая задержка делает изменение яркости плавным и заметным.

Полная программа на C++

fade_led.ino · C++
// Эффект Fade. Светодиод через резистор к D3 и GND. const int ledPin = 3; int brightness = 0; int stepBrightness = 5; void setup() { pinMode(ledPin, OUTPUT); } void loop() { analogWrite(ledPin, brightness); brightness += stepBrightness; if (brightness <= 0 || brightness >= 255) { stepBrightness = -stepBrightness; } delay(30); } 
// Эффект Fade. Светодиод через резистор к D3 и GND.
const int ledPin = 3;
int brightness = 0;
int stepBrightness = 5;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, brightness);
  brightness += stepBrightness;

  if (brightness <= 0 || brightness >= 255) {
    stepBrightness = -stepBrightness;
  }
  delay(30);
}
Проверка результата: свечение становится ярче, затем постепенно угасает. Если нет плавности, убедись, что провод подключён к PWM-пину D3, а не к D4.
